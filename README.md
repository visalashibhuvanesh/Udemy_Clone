Udemy Clone Website 🎓

This project is a Udemy-inspired online learning platform website created entirely using HTML and CSS.

I developed this project from scratch to practice and demonstrate my understanding of frontend web development concepts. The website is designed to recreate the look and structure of an online course platform, including navigation, course categories, course listings, pricing, ratings, and a footer section.

✨ Features

🔎 Search bar for courses

📚 Course category navigation

🎯 Recommended courses section

⭐ Course ratings and reviews

💰 Course pricing and discounted prices

💻 Popular courses section

📱 Structured and organized webpage layout

🔗 Navigation links

🦶 Footer with multiple sections and links

🛠️ Built With: HTML5 & CSS3

🎯 Purpose of the Project
The main purpose of this project was to strengthen my understanding of HTML and CSS by building a complete website from scratch.
While developing this project, I practiced concepts such as:

*HTML page structure

*CSS styling

*Flexbox and layouts

*Margins and padding

*Borders and spacing

*Images

*Navigation

*Course card layouts

*Positioning and alignment
